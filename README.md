# TP4_casse_brique
Bonjour, merci d'avoir téléchargé notre Casse briques :) 
Voici quelques informations importantes afin de profiter d'une meilleure expérience de jeu:

Pour jouer au jeu, lancez le fichier lanceur.py.

# Informations générales:
- ATTENTION: l'affichage du jeu est prévu pour un écran 1920*1080
- Le jeu est composé de 5 niveaux
- Le niveau se termine quand toutes les briques sont cassées
- Les vies ne sont pas réinitialisées au début de chaque niveau
- Si le joueur meurt, il doit recommencer depuis le premier niveau 
- Le score et les vies restantes sont affichés en haut de la fenêtre de jeu
- Appuyez sur la touche espace pour mettre lejeu en pause
- Appuyez sur les flèches droite et gauche pour vous déplacer
- Après un game over vous devez rouvrir le jeu pour recommencer

# Informations sur le joueur :
- Vous avez trois vies vous en perdez une si vous laissez la balle passer
- Chaque choc avec une brique vous rapporte 10 points

# Informations sur les briques :
- Pour le moment aucune, mais à l'avenir, la durté et les récompenses (bonus) aléatoire

# Informations sur les codes triches :
- Appuyez sur i pour devenir immortel (appuyez sur m pour arrêter ce code triche)
- Appuyez sur n pour passer au niveau suivant (en développement)
- Appuyez sur g pour passer en mode garder la balle (en développement)

# Information CAPITALE :
- Pensez à bien vous amuser lors de vos parties et bonne chance ;)
